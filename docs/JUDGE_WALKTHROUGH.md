# A short judge walkthrough

**Decision:** What culturally grounded experience should a local founder prototype next?

Start at `/studio/`. The cinematic home page is an optional introduction. Page visits do not issue Qloo queries. A new brief or explicit evidence test can; held answers are reused and labelled.

New visitors can open **Guided tour** in the header, or follow `/studio/?tour=1`. Its six steps point to the real interface. It can be paused and replayed, handles an empty workspace, and never starts a lookup automatically.

1. Choose **Run the example brief**, or enter your own business, audience and location. Follow the actual events in the research workspace. Missing evidence must be reported rather than replaced.
2. In the concept studio, choose a direction. Inspect its Qloo sources and provenance: source IDs, workflow, request, returned excerpt and timing. Counts of citations are not correctness scores.
3. Choose **Test the evidence**. Read the claim, falsifier, policy and verdict scope. A supported verdict is about an anchor in this retrieved sample. A contested verdict is a valid outcome. Missing checks should leave it unproven.
4. Choose another returned anchor. The screen should identify the alternative and original reference, and state that the concept has not been recomposed. The verdict may change or remain the same; do not stage a predetermined outcome.
5. Choose **Trace evidence dependence** and remove a place. Inspect the recomposition: that place must disappear from descriptions, pictures, citations and anchor. If insufficient evidence remains, the UI should say so.
6. Export the brief or create a share link. Open the link in a second browser. Check that the same directions, evidence and any recorded verdict return.
7. Open **Decision notebook** for the selected direction. Define a hypothesis, proceed/stop criteria and a field method. Save and reopen the record; observations should start blank. Download it with its Qloo citations. Founder notes stay separate from cultural verdicts and from shared exploration links.

For deeper exploration, use **Investigate**, **Compare audiences** or optional model analysis. These can spend additional quota. They are not needed to understand the central compose → challenge → recompose interaction.

## Review failure paths

- A new/private browser with no saved results should offer a brief, not a synthetic answer.
- An unavailable API should show an explanation and a way back to edit the brief.
- An unresolved audience should allow editing or another audience.
- A missing photo should be stated, not replaced with an unrelated venue.
- Changing the result while a test is running must not attach the old result's verdict to new directions.
- With the model disabled, citation counts, deterministic composition and challenge remain usable.

Before submitting, repeat this on the externally hosted URL. Local checks cannot verify public hosting, third-party uptime or judge access.
