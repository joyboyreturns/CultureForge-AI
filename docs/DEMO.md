# A credible three-minute demonstration

Use the hosted URL after deployment, not localhost in a submission. Verify it
in a private window. Run the smoke check and inspect `/api/examples` first;
"Evidence held" means retrieval is held, not that model work is instantaneous.

| Time | Actual interaction | What it demonstrates |
| --- | --- | --- |
| 0–15 s | Open the studio. Read “Make an idea answer to its evidence.” | Qloo supplies sources; CultureForge proposes directions and lets the reader challenge them. |
| 15–30 s | Under **Replay real explorations**, open the recorded Tokyo artisan bakery run, if saved on this service. Point to its acquisition timestamp and composer version. | An authentic recorded result, explicitly not a fresh execution. Saved runs are local to the service's persistent disk. |
| 30–60 s | In **What is this answer built on?**, select a direction and then a returned bakery. Expand **Reference relevance**. | Exact source → proposal citations, direct versus indirect references, category and geographic gaps. Solid lines attach citations; dashed lines represent CultureForge interpretation. |
| 60–90 s | Click **Remove a source and compare**, then **Run the dependence test**. Select the primary bakery's row and apply its rebuild. | An anchor removal can change descriptions, photographs and citations. Removing an unused source can leave the answer unchanged. Model naming differences are excluded from this comparison. |
| 90–120 s | Restore the original. Choose **Evidence test profile**, then **Test the evidence**. | Supported, contested and unproven are possible. Show the checks that actually completed; do not promise a contested result for this particular brief. A failed request is not negative evidence. |
| 120–150 s | Open a source's provenance or inspect the recorded agent analysis. | Allowlisted requests, returned IDs, stated uncertainties and rejected claims. A run without a completed ranking or audience comparison has no comparative model winner. |
| 150–180 s | Export **PDF report** or **Export brief**. | A portable proposal with source IDs, relevance assessments, limits and any recorded verdicts. |

Keep a separate live path: **New exploration**, enter **Artisan bakery** as the
business idea, describe the morning commuters, and use **Tokyo, Japan**. Confirm
only audience seeds you intend to use. The initial rule answer appears as soon
as retrieval and relevance assessment finish; bridge and model work remain
labelled pending. The trace records completed operations, not simulated stages.

A live run may exceed ninety seconds. Use the recorded replay for immediate
exploration and say which path is on screen. Do not equate a replay's timings
with a cold request. Do not promise that the current evidence demonstrates
preorder behavior, opening hours, commuter access, demand or willingness to pay.

If retrieval fails, use the stated recovery action to revise the brief. If
polling loses its connection, reconnect to the same run. Reload can resume its
identifier while the same backend process is alive; a server restart loses
in-flight runs. Completed explorations survive on the configured persistent disk.
